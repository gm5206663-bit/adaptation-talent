# Modules — one file per holder

Every file in this folder is a **character- and universe-specific module** built beneath
the universal core, exactly as §71 (the module template) and §76 (the amendment rule)
require. **A module never rewrites the core.** It translates the law for one holder, in
one world, at a recorded checkpoint.

## How to read a module

1. **Check its date and authority line first.** Modules open by naming the ruling that
   created them and the version of the universal core they sit beneath.
2. **Expect path references to the original repository.** Module files are preserved as
   written — a reference like `blue_silver/ADAPTATION_TALENT.md`,
   `soul_land_4_fire_phoenix/bible/…`, or `/home/user/uploads/…` is a *historical receipt*
   of where the file was born and where the master lived at that time. The current
   canonical location of the universal core is
   [`../canon/MASTER-FOUNDATION.md`](../canon/MASTER-FOUNDATION.md); the mapping of every
   old path to its current home is in
   [`../provenance/COPIES-AND-TWINS.md`](../provenance/COPIES-AND-TWINS.md).
3. **Never edit a module to make a scene work.** Amendments follow §76 — state the rule
   being changed, why, which continuities are affected, and how contradictions are
   repaired — and a universal change requires an explicit author amendment.

## The module shape (§71, seven parts)

Every full module follows the template: **Identity · Local reality · Starting adaptation ·
Current source architecture · Current ledger · Progression path · Continuity.**
[lan-shen.md](lan-shen.md) is the audited reference implementation — its §5 panel carries
all 34 rows of the §69 standard.

## For a brand-new holder

Use the §71 template (described in [docs/04](../docs/04_writing_it.md)), then read two
existing modules: one that holds a *contradiction* in its premise
([blue-silver.md](blue-silver.md) — "hold BOTH truths at once") and one that translates the
Talent into a world with no cultivation at all ([eternal-oc-mcu.md](eternal-oc-mcu.md)).
Those two shapes cover most new cases.
